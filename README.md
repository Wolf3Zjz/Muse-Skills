# Muse-Skills

A public collection of reusable skills: document beautification, frontend design,
theming, brand guidelines, F1 data, web mini-games, and research-direction tooling.
公开的 skill 合集：文档美化、前端设计、主题工坊、品牌规范、F1 数据、网页小游戏、研究方向工具。

## Skills

| Skill | Description / 说明 |
|---|---|
| `document-polisher` | 10 premium brand themes for DOCX / 10 套品牌主题的 DOCX 美化 |
| `frontend-design` | Production-grade frontend interfaces / 高质量前端界面生成 |
| `theme-factory` | Theming toolkit for artifacts / 给产出物换主题的工具箱 |
| `brand-guidelines` | Anthropic brand colors & typography / Anthropic 品牌色与字体规范 |
| `f1-fastf1` | Formula 1 data via FastF1 (2018+) / F1 真实比赛数据 |
| `game-dev` | Web mini-games & desktop widgets playbook / 网页小游戏与桌面小工具开工打法 |
| `research-direction` | Research direction vetting for CFD / turbomachinery / 面向流体机械的选题论证框架 |

## Installation note / 安装说明

`f1-fastf1` needs a one-time venv setup — this repo does not ship `.venv/`.
Follow [`skills/f1-fastf1/INSTALL.md`](skills/f1-fastf1/INSTALL.md),
whose steps were verified end-to-end in a fresh venv (with a real run screenshot).

`f1-fastf1` 需要一次性的 venv 安装（仓库不含 `.venv/`）。
按 [`skills/f1-fastf1/INSTALL.md`](skills/f1-fastf1/INSTALL.md) 操作，
其中的步骤已在全新 venv 中真实跑通验证（附真实运行截图）。
