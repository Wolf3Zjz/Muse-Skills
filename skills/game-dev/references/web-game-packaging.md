# 网页小游戏坑位：单 HTML 离线打包路线

> 背景：3D颜料大战（2026-09-30）。Three.js 3D 引擎全部内联进单个 HTML（约 925KB），
> Google 字体加载失败不影响游戏。成品：`workspace/your_files/3d/3d.html`。
> 已知：手机支持触控；微信文件预览可能禁用 JavaScript；未经实机验证不承诺 iPhone"文件"App 直接运行。

## 路线：所有依赖打包进单个 HTML

- **做法**：JS 引擎、CSS、图片/音频素材（小体积转 base64）全部内联，一个 `.html` 就是全部。
- **为什么**：国内朋友双击即玩，不用挂梯子、不开服务器、不配环境；发文件即分发。
- **开工检查项**：
  - [ ] 无外部 `<script src="http...">` / `@import` 指向 CDN 的核心依赖（统计/字体等非核心除外，且必须可失败）。
  - [ ] 体积心里有数：3D 引擎内联约 1MB 级可接受；超过 5MB 考虑素材压缩。
  - [ ] 断网双击打开，游戏完整可玩（这是硬标准）。

## 坑：外部字体失败不能影响布局和可玩性

- **现象**：Google Fonts 在国内加载失败，页面字体回退错乱或长时间白屏等字体。
- **做法**：`font-family` 必须写完整 fallback 栈，系统字体兜底；字体用 `display=swap`，不等它。
- **开工检查项**：
  - [ ] 每个自定义 `font-family` 后面都跟了 `"PingFang SC","Microsoft YaHei",system-ui,sans-serif` 这类 fallback。
  - [ ] 开发者工具里 block 掉 fonts.googleapis.com 刷新，布局不错乱、游戏可玩。
- **最小示例**：
  ```css
  font-family: "ZCOOL KuaiLe", "PingFang SC", "Microsoft YaHei", sans-serif;
  ```

## 移动端与分发注意

- 手机触控：操作区加虚拟按键/触控事件，不能只有键盘鼠标。
- 微信文件预览可能禁用 JavaScript：提前跟用户说明，用浏览器或双击打开。
- 实机声明纪律：没在真机上测过的，一律写"未经实机验证"，不承诺"一定能跑"。

## 交付检查项

- [ ] 断网双击：完整可玩。
- [ ] 字体 404：布局正常、可玩。
- [ ] 单文件体积记录在案。
- [ ] 分发说明写清：双击即玩 / 手机浏览器打开 / 微信预览可能不可用。
- [ ] 未实机验证的项明确标注，不写"应该没问题"。
